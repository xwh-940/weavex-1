## 简短项目描述草案

以下为可用于项目介绍或简历的三条候选表述，分别对应实现、持续行为和验证；具体篇幅可按用途压缩。

- **运行环境与协作机制：** 基于 Python 自研多智能体运行环境，管理独立会话、工具执行、权限与消息投递；支持 Agent 因信息缺口发起新协作，取得外部结果后继续原问题，并将模型执行后端与宿主状态管理分离。
- **共享材料与持续反馈：** 支持将判断写成其他参与者可取得的材料，记录并复用答案的来源依赖；相关来源变化后重新交付受影响的问题，由模型更新答案或保留原结论，保留历次回答并增量传递材料。
- **验证与工程迭代：** 完成 12 次相关／无关变化的真实模型主对照，核对答案更新、保留与回传；结合调用轨迹诊断缓存与工具执行问题，分别保留成功样本、失败和解释边界。

篇幅有限时，第一条优先保留主动协作，第二条优先保留来源依赖与复查。后端接口、共享材料细节和缓存数值可留在项目中展开。12 次仅指原答案复查主矩阵，不包含新增案例，也不表示全部实验均成功。

更偏 Harness 的介绍可以用[缓存诊断案例](cases/cache-continuity.md)替换第三条的篇幅，但应保留“特定三参与者、29 次调用回归中的输入 token 加权命中率”这一限定。
