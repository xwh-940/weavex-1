# 实现与证据边界

## 当前运行环境

- 单进程、内存态、FIFO 串行处理到达事件。多 Agent 不表示已实现并行计算或分布式执行。
- 会话、材料和依赖持续到 reset；没有跨进程持久化、检查点恢复或自动对话压缩。
- 默认单次模型活动最多 12 轮工具交互，`run_until_idle` 默认最多 100 个到达事件。超限可报错，未实现通用自动恢复。
- 队列为空不代表所有问题已解决；没有新事件时，未完成责任可以继续保留。
- 内置世界工具沿引用读取、新增文本与引用。没有内置通用浏览器、Shell、向量检索或自动工具编译。
- 新增内容不会广播给所有参与者。只有匹配已有观察关系的新增引用，才进入对应变化交付链。
- 来源依赖并不证明来源真实或充分；模型仍可能漏选依据、错误保留答案或给出错误答案。
- 默认 provider 适配使用 Chat Completions，并带有特定 thinking 传输行为。任意兼容端点不保证都支持该协议；多工具响应当前只采用第一项。
- 调试工作台是开发者全局观察面。页面可见全局状态不意味着各 Agent 也能读取它。

## 实验解释

- 答案复查的 12 次主对照来自 2026-08-28 的小型合成场景；材料明确表达了安全相关或无关变化。它不是困难相关性判断评测，也不是总体准确率。
- 同批另有 6 次扩展运行，其中包含一次错误保留旧答案。完整 18 次记录均保留。
- 这些条件比较的是信息变化类型与回传路径，没有建立 WeaveX 对强单 Agent 或其他框架的优势。
- 缓存的 97.70% 是一个具体回归的输入 token 加权比例。不能与不同历史任务直接相减，也不能据此推算费用或延迟下降。
- 初次缓存回归未闭环；提高输出上限后重新运行。两次可能共享服务端暖前缀。
- 历史记录未完整嵌入当时源码与提示词 revision，不能声称当前源码精确复现其全部条件。
- 当前确定性示例和原有自动化测试验证运行机制；脚本预设行为不属于模型自主能力证据。

## 后续值得检验的方向

同信息与调用预算下的强基线；更模糊或冲突的新证据；长期上下文增长；错误保留后的恢复；动态协作的收益与成本。这里是后续实验问题，不表示已经获得结果。
